## Find your way around

This is a small, fictional team's working library. It holds the decisions behind a publishing system, the steps people repeat, and the context that is easy to lose between projects.

Start with the collections in the sidebar. **Guides** explain how to do something. **Systems** describe how the pieces fit. **Practices** hold the habits that keep the work dependable.

> A useful note helps the next person make a decision. Give them the context, not just the conclusion.

## Follow the connections

Read [[publishing-a-note]] when you are ready to contribute. For the larger picture, [[system-map]] explains how a source note becomes a published page.

You can search for an exact passage, but you do not need a query to begin. Follow the links, use the page contents, or return to the overview at any time.

## Keep the trail useful

When a note changes, review the links around it. The [[review-checklist]] is a starting point for a small, deliberate review.

## Navigation

The page directory and the contents of a note are separate ways to navigate. A heading link should always lead to the note itself.
