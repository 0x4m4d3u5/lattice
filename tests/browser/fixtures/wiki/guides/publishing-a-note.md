## Start with the question

Write the question the note answers before adding background. A clear title and a one-sentence description make the page useful in both the directory and search.

## Add the missing context

Explain the choice, the alternatives that mattered, and what would cause you to revisit it. Link to [[system-map#Source to page|the publishing flow]] instead of copying an explanation that already has a home.

## Review before publishing

Use [[review-checklist]] to check the result. Read the published page as well as the source: headings, links and navigation should make sense together.
