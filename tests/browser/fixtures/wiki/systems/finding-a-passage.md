## Browse for context

Use the page directory when you are learning the shape of the library. Collections group related notes, while links reveal the connections between them.

## Search for a detail

Search for a phrase or a few distinctive terms. Tag filters narrow the results to notes that match every selected tag. Each result links to the published page.

For the first steps, return to [[getting-started]].
